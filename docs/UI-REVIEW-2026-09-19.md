# UI consistency and compact-width review

The monitor previously placed its title, rod/recording indicators, Observe button,
recording limit and preview option in one nonwrapping row. Observe clipped at
compact widths and used the default Windows button appearance.

## Changes

- Shared secondary button template with consistent spacing, border, hover,
  pressed, keyboard-focus and disabled states. Start/Stop remains prominent.
- Observe has a dedicated wrapping action row. Recording options and live preview
  expand separately. Recordings folder/export actions live with recording options.
- Window tools and standalone tasks expand on demand; tracking metrics sit behind
  Tracking details. Status and current action remain visible.
- Rod/cast/theme settings and automation toggles use two columns. Aquarium and
  crate controls sit below their labels instead of competing for horizontal space.
- The version badge wraps with the title. The settings footer has its own grid
  row. ComboBox content reserves room for its arrow.
- Observe uses Stop recording while active and cannot be invoked again while busy.

## Verification

Release build: `artifacts/ui-final-build`, zero warnings/errors.
Full suite: 314 passed, zero failed, one existing missing-private-fixture skip.
TRX: `artifacts/ui-final-tests/ui-final.trx`.

Native window review covered the default 470-DIP width and minimum 380-DIP width
at the current Windows scale, including a visible vertical scrollbar, expanded
recording options, window tools, and all fishing settings through the footer.
Observe, secondary actions, settings fields and footer were visible without
horizontal clipping. Other Windows scaling levels have not been checked.

The previous fishing build was closed for the UI review. The final UI build is
open for review. An Observe smoke attempt returned to Ready after the macro was
foregrounded (its existing capture visibility guard); a sustained Observe trial
is not claimed. This review does not establish idle, reconnect or soak acceptance.
