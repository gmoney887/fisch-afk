## Detection and capture

The pointed-marker/flared-cap reader is isolated from the standard AGY path.
It uses reviewed grayscale UI references, current original marker tips, cap
corners/shoulders and an independently complete meter. It does not use rod colors,
desktop height as UI scale, cached pixels or predicted body coordinates.
The reviewed family reader from e583ded is reused without that archive's large
vision stack or controller. A new fast path re-proves one meter hint in current
pixels before skipping cold nomination; marker and body proofs remain shared.

Ordinary positive observations run the existing reader without a pointed scan.
Current ordinary bar/meter continuity avoids an unnecessary family search during
a missing needle. A current pointed hint changes search order only. A miss runs
the AGY reader immediately; resize, stop, reel end or lost context clears hints.
Decorative rail ridges are not published as measured stationary endpoints.

The legacy entry/reel crop cuts off Webweaver's meter. Entry now acquires full
context, and lure/scene checks reuse existing full frames. Subsequent reel captures
retain a region derived from current meter/marker geometry, unioned with the
ordinary crop. The native fixture keeps the original horizontal capture width;
the vertical region expands to retain the marker and meter. No input policy or
control gain was tuned for these fixtures. Extra entry capture cost is distinct
from repeated reel cost.

## Diagnostics

Decision journals add separate CaptureLatencyMs, DetectionLatencyMs,
FamilyProbeLatencyMs, DetectorPath and capture/decision clock timestamps.
Existing VisionLatencyMs remains unchanged (it includes capture). Guarded input
events log the capture timestamp behind the latest decision and its age when the
edge was delivered. These fields observe existing actions; they do not schedule
input. The native timing test checks forty fresh clones of a measured crop with
the original coordinate assertions and p95<=25ms. The proposed10ms goal has not
been established. First acquisition, process/JIT state and repeated costs must be
reported separately. Frame clones and synthetic sample holds are not new attempts.

## Validation and trial limits

Reviewed pixels cover original bounds/target, hidden endpoint, disappearance,
grayscale/channel changes, independent UI scale/origin, erasures, ordinary return,
boat/Styx/pool negatives, capture continuity and guarded Stop/focus/resize.
The original21->24->25->29 relative times are preserved in an engine script;
holding sparse images at70/120ms is explicitly synthetic. It verifies the player
Haddock catch (not the companion reward), then readiness for the next reel.
It does not establish instantaneous game acceleration, a live catch rate or Perfect.
Styx hazard steering is not added in this increment.

Run Fast and Full on the frozen source before packaging. The Windows native runner
defers when another build/test is active and monitors for a foreign testhost. On a
detected collision it stops only this worktree's host and rejects the run. AGY's
processes and the interactive AFK app are never stopped. This is monitoring, not
a shared lock honored by AGY. Rejected runs retain their logs.

Only a separate local package is produced. No publication or interactive launch.
Portable contents/assets/runtime are inspected without starting another instance.
Final source identity, results, timing samples and package hashes are stored in
ignored artifacts/webweaver-agy-20261026. No personal recordings or fixtures ship.
